🧹 A Florida Cleaning — Business Website

A modern business website concept for a Florida-based cleaning service, created using a Vibe Coding / AI-assisted development workflow.

🔗 Live Demo: https://cleanbiz-demo.vercel.app

🎯 Project Overview

This project was created to build a professional online presence for a cleaning service business.

The website focuses on presenting the business and its services through a clean, modern, responsive interface designed around a real-world business use case.

🤖 Vibe Coding Approach

The website was developed using a Vibe Coding workflow, where AI coding tools were used as a development assistant throughout the build.

The development process included:

- 💡 Planning the website structure
- 🤖 Using AI to accelerate code development
- 🎨 Translating design ideas into UI
- 🔧 Debugging and refining generated code
- 📱 Improving responsive behavior
- 🔄 Iterating on sections and user experience
- 🚀 Deploying the finished project

AI was used to accelerate implementation, while the project was reviewed, customized, tested, and refined during development.
